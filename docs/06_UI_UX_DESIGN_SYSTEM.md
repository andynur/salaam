# UI/UX Design System

## Product direction

Use a Jira-inspired productivity interface for teachers and administrators, and a
simpler task/progress interface for students. The visual system is white and navy with
blue actions and a restrained gold accent.

## Layout

Use a responsive shell with a clear navigation hierarchy, readable content width, and
internal scrolling for wide tables. The 390px phone viewport and 820px tablet viewport
must not develop document-level horizontal overflow.

## Interaction states

Every data view must provide loading, empty, error, retry, and success states. Disable
a form while a mutation is in progress and prevent duplicate submissions. Preserve
entered values when correcting validation errors.

## Accessibility

Use semantic headings, labels, keyboard focus, visible error messages, sufficient
contrast, reduced-motion support, and touch targets that remain usable on phones.
